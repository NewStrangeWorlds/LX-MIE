API reference¶

All functions and types are declared in the namespace lxmie. The definitions of the physical quantities are given in Conventions and units.

Single particles¶

Header: mie.h

struct MieResult¶

Result of a Mie calculation for a single particle.

double q_ext¶

Extinction efficiency.

double q_sca¶

Scattering efficiency.

double q_abs¶

Absorption efficiency, calculated as the difference of the extinction and scattering efficiencies.

double asymmetry_parameter¶

Asymmetry parameter \(g\).

MieResult Mie(std::complex<double> refractive_index, double size_parameter)¶

Calculates the Mie efficiencies and the asymmetry parameter.

Parameters:

  • refractive_index – Complex refractive index of the particle. The sign of the imaginary part does not matter.

  • size_parameter – Size parameter \(x = 2 \pi r / \lambda\).

Throws:

std::runtime_error – if the calculation fails.

MieResult Mie(std::complex<double> refractive_index, double size_parameter, std::size_t nb_legendre_moments, std::vector<double> &legendre_moments)¶

Additionally calculates the coefficients of the Legendre series of the phase function.

Parameters:

  • refractive_index – Complex refractive index of the particle.

  • size_parameter – Size parameter.

  • nb_legendre_moments – Number of Legendre series coefficients.

  • legendre_moments – Output: the coefficients \(\chi_0, \chi_1, \ldots\). The vector has to contain at least nb_legendre_moments elements. It is not resized by the function.

Throws:

std::runtime_error – if the calculation fails.

MieResult Mie(std::complex<double> refractive_index, double size_parameter, const std::vector<double> &angular_grid, std::vector<std::complex<double>> &s1, std::vector<std::complex<double>> &s2)¶

Additionally calculates the scattering amplitudes \(S_1\) and \(S_2\) on a grid of scattering angles.

Parameters:

  • refractive_index – Complex refractive index of the particle.

  • size_parameter – Size parameter.

  • angular_grid – Cosines of the scattering angles.

  • s1 – Output: scattering amplitude \(S_1\) at each angle.

  • s2 – Output: scattering amplitude \(S_2\) at each angle.

Throws:

std::runtime_error – if the calculation fails.

The vectors s1 and s2 have to contain at least as many elements as angular_grid. They are not resized by the function.

double phaseFunction(std::complex<double> s1, std::complex<double> s2, double size_parameter, double q_sca)¶

Returns the normalised phase function for a single scattering angle,

\[p = \frac{2}{x^2 \, Q_\mathrm{sca}} \left( |S_1|^2 + |S_2|^2 \right) \ .\]
Parameters:

  • s1 – Scattering amplitude \(S_1\).

  • s2 – Scattering amplitude \(S_2\).

  • size_parameter – Size parameter of the particle.

  • q_sca – Scattering efficiency of the particle.

std::vector<double> phaseFunction(const std::vector<std::complex<double>> &s1, const std::vector<std::complex<double>> &s2, double size_parameter, double q_sca)¶

Returns the normalised phase function for a set of scattering angles.

Parameters:

  • s1 – Scattering amplitudes \(S_1\).

  • s2 – Scattering amplitudes \(S_2\), with at least as many elements as s1.

  • size_parameter – Size parameter of the particle.

  • q_sca – Scattering efficiency of the particle.

Size distributions¶

Header: size_distribution.h

constexpr std::size_t default_nb_distribution_points = 500¶

Default number of radius grid points of the analytical size distributions.

struct SizeDistribution¶

A particle size distribution, discretised into a set of quadrature nodes. The struct can be filled directly, e.g. with the size bins of a cloud model, or created with one of the functions below.

std::vector<double> radius¶

Particle radii.

std::vector<double> weight¶

Number of particles represented by each node, i.e. \(n(r_i) \, \Delta r_i\) for a continuous distribution \(n(r) = \mathrm{d}N/\mathrm{d}r\). The weights do not need to be normalised. All size-integrated results are normalised to the total number of particles, i.e. the sum of all weights.

SizeDistribution logNormalDistribution(double median_radius, double sigma_g, std::size_t nb_points = default_nb_distribution_points, double r_min = 0.0, double r_max = 0.0)¶

Log-normal distribution with the median radius \(r_m\) and the geometric standard deviation \(\sigma_g\),

\[n(r) \propto \frac{1}{r} \exp \left( - \frac{\ln^2 (r / r_m)}{2 \ln^2 \sigma_g} \right) \ .\]
Parameters:

  • median_radius – Median radius, has to be positive.

  • sigma_g – Geometric standard deviation, has to be larger than 1.

  • nb_points – Number of radius grid points (at least 2).

  • r_min – Smallest radius. If zero, the integration limit is chosen automatically.

  • r_max – Largest radius. If zero, the integration limit is chosen automatically.

Throws:

std::invalid_argument – for invalid parameters.

SizeDistribution gammaDistribution(double effective_radius, double effective_variance, std::size_t nb_points = default_nb_distribution_points, double r_min = 0.0, double r_max = 0.0)¶

Gamma distribution following Hansen & Travis (1974) with the effective radius \(a\) and the effective variance \(b\),

\[n(r) \propto r^{(1-3b)/b} \exp \left( - \frac{r}{ab} \right) \ .\]
Parameters:

  • effective_radius – Effective radius, has to be positive.

  • effective_variance – Effective variance, between 0 and 0.5.

  • nb_points – Number of radius grid points (at least 2).

  • r_min – Smallest radius. If zero, the integration limit is chosen automatically.

  • r_max – Largest radius. If zero, the integration limit is chosen automatically.

Throws:

std::invalid_argument – for invalid parameters.

SizeDistribution powerLawDistribution(double r_min, double r_max, double exponent, std::size_t nb_points = default_nb_distribution_points)¶

Power-law distribution \(n(r) \propto r^{-p}\) between r_min and r_max.

Parameters:

  • r_min – Smallest radius, has to be positive.

  • r_max – Largest radius, has to be larger than r_min.

  • exponent – Exponent \(p\).

  • nb_points – Number of radius grid points (at least 2).

Throws:

std::invalid_argument – for invalid parameters.

SizeDistribution tabulatedDistribution(const std::vector<double> &radius, const std::vector<double> &dn_dr)¶

Tabulated distribution \(n(r) = \mathrm{d}N/\mathrm{d}r\). The weights are obtained from the trapezoidal rule.

Parameters:

  • radius – Particle radii, strictly increasing (at least two).

  • dn_dr – Values of the distribution at these radii.

Throws:

std::invalid_argument – for vectors of different sizes, fewer than two radii, or radii that are not strictly increasing.

Size-integrated calculations¶

Header: size_distribution.h

struct MieDistributionResult¶

Size-integrated optical properties, see Size-integrated quantities. Cross sections are mean values per particle, in units of the squared length unit that is used for the wavelength and the particle radii.

double c_ext¶

Mean extinction cross section.

double c_sca¶

Mean scattering cross section.

double c_abs¶

Mean absorption cross section.

double q_ext¶

Effective extinction efficiency, i.e. the mean extinction cross section divided by the mean geometric cross section.

double q_sca¶

Effective scattering efficiency.

double q_abs¶

Effective absorption efficiency.

double asymmetry_parameter¶

Asymmetry parameter, weighted by the scattering cross sections.

double geometric_cross_section¶

Mean geometric cross section \(\langle \pi r^2 \rangle\).

double effective_radius¶

Effective radius \(\langle r^3 \rangle / \langle r^2 \rangle\).

MieDistributionResult MieDistribution(std::complex<double> refractive_index, double wavelength, const SizeDistribution &distribution)¶

Mie calculation integrated over a particle size distribution.

Parameters:

  • refractive_index – Complex refractive index of the particles. The sign of the imaginary part does not matter.

  • wavelength – Wavelength, in the same units as the particle radii.

  • distribution – The size distribution.

Throws:

  • std::invalid_argument – if the wavelength is not positive or the distribution is invalid (different numbers of radii and weights, no radii, radii that are not positive, negative weights, or a sum of the weights that is not positive).

  • std::runtime_error – if one of the Mie calculations fails.

Nodes with a weight of zero are skipped.

MieDistributionResult MieDistribution(std::complex<double> refractive_index, double wavelength, const SizeDistribution &distribution, std::size_t nb_legendre_moments, std::vector<double> &legendre_moments)¶

Additionally returns the Legendre series of the size-averaged phase function.

Parameters:

  • refractive_index – Complex refractive index of the particles.

  • wavelength – Wavelength, in the same units as the particle radii.

  • distribution – The size distribution.

  • nb_legendre_moments – Number of Legendre series coefficients.

  • legendre_moments – Output: the coefficients of the Legendre series. The vector is resized to nb_legendre_moments elements.

MieDistributionResult MieDistribution(std::complex<double> refractive_index, double wavelength, const SizeDistribution &distribution, const std::vector<double> &angular_grid, std::vector<double> &phase_function)¶

Additionally returns the size-averaged phase function.

Parameters:

  • refractive_index – Complex refractive index of the particles.

  • wavelength – Wavelength, in the same units as the particle radii.

  • distribution – The size distribution.

  • angular_grid – Cosines of the scattering angles.

  • phase_function – Output: the size-averaged phase function at each angle. The vector is resized to the size of angular_grid.
