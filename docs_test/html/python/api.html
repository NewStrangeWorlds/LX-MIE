API reference¶

This page documents all functions and classes of the lxmie module. The general rules for scalar and batch calls are described in Overview, the definitions of the physical quantities in Conventions and units.

In the signatures below, float | list[float] denotes an argument that is either a scalar or a list. If lists are used, all arguments of this kind have to be lists of the same length and the function returns lists of results.

Single particles¶

lxmie.mie(n_real, n_imag, size_parameter)¶

Calculates the Mie efficiencies and the asymmetry parameter.

Parameters:

  • n_real (float | list[float]) – Real part of the refractive index.

  • n_imag (float | list[float]) – Imaginary part of the refractive index. The sign does not matter.

  • size_parameter (float | list[float]) – Size parameter \(x = 2 \pi r / \lambda\).

Returns:

The efficiencies and the asymmetry parameter.

Return type:

MieResult | list[MieResult]

result = lxmie.mie(1.5, 0.01, 5.0)
results = lxmie.mie([1.5, 1.6], [0.01, 0.02], [5.0, 10.0])
lxmie.mie_legendre(n_real, n_imag, size_parameter, nb_moments)¶

Calculates the Mie efficiencies, the asymmetry parameter, and the first nb_moments coefficients of the Legendre series of the phase function.

Parameters:

  • n_real (float | list[float]) – Real part of the refractive index.

  • n_imag (float | list[float]) – Imaginary part of the refractive index. The sign does not matter.

  • size_parameter (float | list[float]) – Size parameter \(x = 2 \pi r / \lambda\).

  • nb_moments (int) – Number of Legendre series coefficients, starting with \(\chi_0\).

Returns:

A tuple (result, moments). moments is the list of Legendre coefficients \(\chi_0 \ldots \chi_{\mathrm{nb\_moments}-1}\). For list arguments, both elements of the tuple are lists with one entry per particle.

Return type:

tuple[MieResult, list[float]] | tuple[list[MieResult], list[list[float]]]

The first coefficient is always 1, the second one is equal to the asymmetry parameter.

result, moments = lxmie.mie_legendre(1.5, 0.01, 5.0, 16)

results, all_moments = lxmie.mie_legendre([1.5, 1.6], [0.01, 0.02], [5.0, 10.0], 16)
# all_moments[i][l]: coefficient l of particle i
lxmie.mie_amplitudes(n_real, n_imag, size_parameter, angles)¶

Calculates the Mie efficiencies, the asymmetry parameter, and the complex scattering amplitudes \(S_1\) and \(S_2\) at the given angles.

Parameters:

  • n_real (float | list[float]) – Real part of the refractive index.

  • n_imag (float | list[float]) – Imaginary part of the refractive index. The sign does not matter.

  • size_parameter (float | list[float]) – Size parameter \(x = 2 \pi r / \lambda\).

  • angles (list[float]) – Cosines of the scattering angles. The same angles are used for all particles of a batch call.

Returns:

A tuple (result, s1, s2). s1 and s2 are lists with the scattering amplitudes at each angle. For list arguments, all three elements of the tuple are lists with one entry per particle.

Return type:

tuple[MieResult, list[complex], list[complex]] | tuple[list[MieResult], list[list[complex]], list[list[complex]]]

The scattering amplitudes can be converted to the phase function with phase_function().

import math

cos_angles = [math.cos(math.radians(theta)) for theta in range(0, 181, 5)]

result, s1, s2 = lxmie.mie_amplitudes(1.5, 0.01, 5.0, cos_angles)

Note

Due to the internal sign convention of the refractive index (\(m = n - \mathrm{i}k\)), the scattering amplitudes are the complex conjugates of those obtained with the convention \(m = n + \mathrm{i}k\) that is used by, for example, Bohren & Huffman (1983). Intensities, such as \(|S_1|^2\) and \(|S_2|^2\), are not affected.

lxmie.phase_function(s1, s2, size_parameter, q_sca)¶

Calculates the normalised phase function for unpolarised incident light from the scattering amplitudes,

\[p = \frac{2}{x^2 \, Q_\mathrm{sca}} \left( |S_1|^2 + |S_2|^2 \right) \ .\]
Parameters:

  • s1 (complex | list[complex]) – Scattering amplitude(s) \(S_1\).

  • s2 (complex | list[complex]) – Scattering amplitude(s) \(S_2\).

  • size_parameter (float) – Size parameter of the particle.

  • q_sca (float) – Scattering efficiency of the particle.

Returns:

The phase function at the angle(s) of the scattering amplitudes.

Return type:

float | list[float]

In contrast to the other functions, the list version of this function refers to a list of angles for a single particle. For the result of a batch call of mie_amplitudes(), the function has to be called for each particle:

results, all_s1, all_s2 = lxmie.mie_amplitudes(n_real, n_imag, size_parameters, cos_angles)

phase_functions = [
    lxmie.phase_function(s1, s2, x, r.q_sca)
    for s1, s2, x, r in zip(all_s1, all_s2, size_parameters, results)
]
class lxmie.MieResult¶

Result of a Mie calculation for a single particle. All attributes are read-only.

q_ext: float¶

Extinction efficiency.

q_sca: float¶

Scattering efficiency.

q_abs: float¶

Absorption efficiency, \(Q_\mathrm{ext} - Q_\mathrm{sca}\).

asymmetry_parameter: float¶

Asymmetry parameter \(g\).

Note

The printed representation of the result objects, e.g. MieResult(q_ext=3.818319, ...), is rounded to six decimal places. The attributes contain the values with full double precision.

Size distributions¶

A size distribution is represented by a SizeDistribution object. It can be created with one of the following functions or directly from lists of radii and weights. The definitions of the distributions and the choice of the radius grids are discussed in Particle size distributions.

lxmie.lognormal_distribution(median_radius, sigma_g, nb_points=500, r_min=0, r_max=0)¶

Log-normal distribution,

\[n(r) \propto \frac{1}{r} \exp \left( - \frac{\ln^2 (r / r_m)}{2 \ln^2 \sigma_g} \right) \ .\]
Parameters:

  • median_radius (float) – Median radius \(r_m > 0\).

  • sigma_g (float) – Geometric standard deviation \(\sigma_g > 1\).

  • nb_points (int) – Number of radii used for the integration over the distribution (at least 2).

  • r_min (float) – Smallest radius of the grid. If zero, the limit is chosen automatically.

  • r_max (float) – Largest radius of the grid. If zero, the limit is chosen automatically.

Return type:

SizeDistribution

Raises:

ValueError – for invalid parameters.

lxmie.gamma_distribution(effective_radius, effective_variance, nb_points=500, r_min=0, r_max=0)¶

Gamma distribution of Hansen & Travis (1974),

\[n(r) \propto r^{(1-3b)/b} \exp \left( - \frac{r}{ab} \right) \ ,\]

with the effective radius \(a\) and the effective variance \(b\).

Parameters:

  • effective_radius (float) – Effective radius \(a > 0\).

  • effective_variance (float) – Effective variance \(0 < b < 0.5\).

  • nb_points (int) – Number of radii used for the integration over the distribution (at least 2).

  • r_min (float) – Smallest radius of the grid. If zero, the limit is chosen automatically.

  • r_max (float) – Largest radius of the grid. If zero, the limit is chosen automatically.

Return type:

SizeDistribution

Raises:

ValueError – for invalid parameters.

lxmie.power_law_distribution(r_min, r_max, exponent, nb_points=500)¶

Power-law distribution \(n(r) \propto r^{-p}\) between r_min and r_max.

Parameters:

  • r_min (float) – Smallest radius, \(r_\mathrm{min} > 0\).

  • r_max (float) – Largest radius, \(r_\mathrm{max} > r_\mathrm{min}\).

  • exponent (float) – Exponent \(p\). Note the sign: a positive value describes a distribution that decreases with the radius.

  • nb_points (int) – Number of radii used for the integration over the distribution (at least 2).

Return type:

SizeDistribution

Raises:

ValueError – for invalid parameters.

lxmie.tabulated_distribution(radius, dn_dr)¶

Distribution from tabulated values of \(n(r) = \mathrm{d}N/\mathrm{d}r\). The integration weights are calculated with the trapezoidal rule.

Parameters:

  • radius (list[float]) – Particle radii, strictly increasing (at least two values).

  • dn_dr (list[float]) – Values of the distribution at these radii, in arbitrary units.

Return type:

SizeDistribution

Raises:

ValueError – for lists of different lengths, fewer than two radii, or radii that are not strictly increasing.

class lxmie.SizeDistribution(radius, weight)¶

A particle size distribution, discretised into a set of radii and the number of particles represented by each radius.

The constructor directly uses the given radii and weights. This is the appropriate choice for discrete size bins, e.g. from a cloud model, with the number (density) of particles in each bin as weights. In contrast to tabulated_distribution(), the weights are not values of \(\mathrm{d}N/\mathrm{d}r\), but particle numbers.

Parameters:

  • radius (list[float]) – Particle radii. They have to be positive, but do not need to be sorted.

  • weight (list[float]) – Number of particles for each radius. The weights have to be non-negative and do not need to be normalised.

Raises:

ValueError – if the two lists have different lengths.

radius: list[float]¶

The radii of the distribution.

weight: list[float]¶

The weights of the distribution. For a distribution created from a continuous function \(n(r)\), these are the quadrature weights \(n(r_i) \, \Delta r_i\).

len(distribution) returns the number of radii.

Note

radius and weight return copies of the internal data. To change a distribution, a complete new list has to be assigned, e.g. distribution.weight = new_weights. Changing single elements, such as distribution.weight[0] = 0, has no effect.

The radii and weights are validated when the distribution is used in a calculation, see mie_distribution().

Size-integrated calculations¶

The following functions integrate the optical properties over a size distribution. The calculated quantities are defined in Size-integrated quantities.

lxmie.mie_distribution(n_real, n_imag, wavelength, distribution)¶

Calculates the cross sections, efficiencies, and the asymmetry parameter integrated over a size distribution.

Parameters:

  • n_real (float | list[float]) – Real part of the refractive index.

  • n_imag (float | list[float]) – Imaginary part of the refractive index. The sign does not matter.

  • wavelength (float | list[float]) – Wavelength, in the same units as the radii of the distribution.

  • distribution (SizeDistribution) – The size distribution. The same distribution is used for all wavelengths of a batch call.

Returns:

The size-integrated optical properties.

Return type:

MieDistributionResult | list[MieDistributionResult]

Raises:

ValueError – if the lists have different lengths, the wavelength is not positive, or the distribution is invalid (different numbers of radii and weights, no radii, radii that are not positive, negative weights, or a sum of the weights that is not positive).

distribution = lxmie.lognormal_distribution(1.0, 1.5)   # radii in micron

result = lxmie.mie_distribution(1.5, 0.01, 0.55, distribution)
results = lxmie.mie_distribution([1.5, 1.6], [0.01, 0.02], [0.55, 1.0], distribution)
lxmie.mie_distribution_legendre(n_real, n_imag, wavelength, distribution, nb_moments)¶

Like mie_distribution(), but additionally returns the first nb_moments coefficients of the Legendre series of the size-averaged phase function. The coefficients have the same normalisation as those of mie_legendre().

Parameters:

  • n_real (float | list[float]) – Real part of the refractive index.

  • n_imag (float | list[float]) – Imaginary part of the refractive index. The sign does not matter.

  • wavelength (float | list[float]) – Wavelength, in the same units as the radii of the distribution.

  • distribution (SizeDistribution) – The size distribution.

  • nb_moments (int) – Number of Legendre series coefficients.

Returns:

A tuple (result, moments). For list arguments, both elements are lists with one entry per wavelength.

Return type:

tuple[MieDistributionResult, list[float]] | tuple[list[MieDistributionResult], list[list[float]]]

Raises:

ValueError – see mie_distribution().

lxmie.mie_distribution_phase_function(n_real, n_imag, wavelength, distribution, angles)¶

Like mie_distribution(), but additionally returns the size-averaged phase function at the given angles. The phase function has the same normalisation as the one returned by phase_function().

Parameters:

  • n_real (float | list[float]) – Real part of the refractive index.

  • n_imag (float | list[float]) – Imaginary part of the refractive index. The sign does not matter.

  • wavelength (float | list[float]) – Wavelength, in the same units as the radii of the distribution.

  • distribution (SizeDistribution) – The size distribution.

  • angles (list[float]) – Cosines of the scattering angles.

Returns:

A tuple (result, phase_function). For list arguments, both elements are lists with one entry per wavelength.

Return type:

tuple[MieDistributionResult, list[float]] | tuple[list[MieDistributionResult], list[list[float]]]

Raises:

ValueError – see mie_distribution().

import math

cos_angles = [math.cos(math.radians(theta)) for theta in range(0, 181, 15)]

result, phase_function = lxmie.mie_distribution_phase_function(
    1.5, 0.01, 0.55, distribution, cos_angles)
class lxmie.MieDistributionResult¶

Result of a calculation for a size distribution. All attributes are read-only. The length unit is the one used for the wavelength and the radii of the distribution.

c_ext: float¶

Mean extinction cross section per particle (length unit squared).

c_sca: float¶

Mean scattering cross section per particle (length unit squared).

c_abs: float¶

Mean absorption cross section per particle (length unit squared).

q_ext: float¶

Effective extinction efficiency, i.e. the mean extinction cross section divided by the mean geometric cross section.

q_sca: float¶

Effective scattering efficiency.

q_abs: float¶

Effective absorption efficiency.

asymmetry_parameter: float¶

Asymmetry parameter of the distribution, weighted by the scattering cross sections.

geometric_cross_section: float¶

Mean geometric cross section \(\langle \pi r^2 \rangle\) (length unit squared).

effective_radius: float¶

Effective radius \(\langle r^3 \rangle / \langle r^2 \rangle\) (length unit).
